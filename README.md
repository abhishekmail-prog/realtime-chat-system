# Vibe Chat

A full-stack real-time chat application built using the MERN stack.
Vibe Chat provides secure JWT authentication, instant one-to-one messaging
using Socket.IO, image sharing with Cloudinary, live online status,
responsive UI, and profile management.

**Status:** ✅ Completed & Deployed

---

# Features

## Authentication

- User Signup & Login
- JWT Authentication
- Protected Routes
- Persistent Sessions
- Authentication Verification

---

## Real-Time Messaging

- One-to-One Chat
- Instant Messaging with Socket.IO
- Live Online / Offline Status
- Real-Time Message Delivery
- Unread Message Counter
